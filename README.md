# Git Flow для 1C:EDT

Git Flow помогает работать с Git прямо в 1C:EDT. В отдельной панели можно увидеть
изменённые файлы, подготовить их к коммиту, посмотреть историю, переключить ветку
и отправить изменения. Частые операции, для которых обычно нужно открывать
несколько окон, собраны в одном месте.

## Что умеет плагин

- **Работать с файлами.** Панель показывает изменённые и подготовленные файлы.
  Кнопки `+` и `−` добавляют файл в будущий коммит или убирают его оттуда.
  Через контекстное меню можно открыть файл, сравнить изменения и посмотреть
  историю. Отмену правок плагин выполняет после подтверждения.
- **Создавать коммиты.** Сообщение можно написать в несколько строк и отправить
  коммит сочетанием `Ctrl+Enter`. Отправка на сервер после коммита включена по
  умолчанию; её можно отключить кнопкой с шестерёнкой.
- **Синхронизировать ветку.** Плагин проверяет изменения на сервере перед
  отправкой. Если ветка уже изменилась, он пытается сначала получить новые
  коммиты. При конфликте помогает перейти к штатному слиянию в EDT. После
  такого слияния отправку нужно запустить отдельно. Принудительную отправку
  (`force push`) плагин не делает.
- **Переключать ветки.** Ветки показаны деревом: их можно искать, добавлять в
  избранное и выбирать среди локальных и удалённых. Плагин также улучшает
  выбор ветки в штатном окне слияния EDT.
- **Временно убирать изменения.** Быстрый стеш сохраняет текущие правки, а
  команда возврата восстанавливает последний стеш. При создании ветки через
  мастер EDT плагин временно сохраняет локальные изменения и возвращает их
  после закрытия мастера.
- **Показывать историю.** Под списком файлов видны коммиты текущей ветки с
  графом, автором и сообщениями. Для коммита доступны сравнение, копирование
  хеша и другие действия через контекстное меню.

Плагин также добавляет команды в меню **Git Flow** и частично в меню **Team** у
проекта. В штатном окне **Индексирование Git** кнопка **Фиксировать + Push**
использует проверку удалённой ветки от Git Flow.

В меню **Git Flow → Другие Git-действия** есть команды для отдельных случаев:
отменить последний коммит, перенести его в другую ветку, создать коммит в новой
ветке, получить изменения для всех проектов и сформировать сообщение коммита
по имени ветки.

## Как начать работу

После установки откройте **Git Flow → Открыть Git-панель**. Её также можно найти
через **Окно → Показать представление → Другие… → Git Flow → Git**.

Панель сама выбирает репозиторий. Если в рабочем пространстве их несколько,
выберите нужный вверху панели. Дальше обычный порядок работы такой:

1. Нажмите `+` рядом с файлами, которые хотите включить в коммит.
2. Напишите сообщение коммита.
3. Нажмите основную кнопку. Она создаст коммит и, если отправка включена,
   синхронизирует ветку с сервером.

Круговая стрелка рядом со счётчиками входящих и исходящих коммитов выбирает
действие по состоянию ветки: проверить сервер, получить изменения или отправить
свои. Название ветки вверху панели открывает выбор веток.

## Установка в EDT

Для установки скачайте ZIP-архив Git Flow из раздела **Releases** этого
репозитория. Это один и тот же архив для Windows и macOS. ZIP не нужно
распаковывать или копировать в папку `plugins`.

1. В EDT откройте **Справка → Установить новое ПО… → Добавить… → Архив…**.
2. Выберите ZIP-архив Git Flow, затем компонент **Git Flow**.
3. Завершите установку и перезапустите EDT.
4. Откройте Git-панель через меню **Git Flow**.

Если очень ранняя версия устанавливалась вручную через `dropins`, перед новой
установкой закройте EDT и удалите старую папку
`<каталог EDT>\1cedt\dropins\gitflow`.

Заявленный минимум — EDT 2025.1.1. На Windows пользователь проверил плагин
в EDT 2025.2.6. Сборка выполняется на macOS с EDT 2026.1.2; запуск плагина в
этой версии пока не подтверждён. Совместимость именно с EDT 2025.1.1 нужно
проверить отдельно. Если установка сообщает о несовместимых зависимостях,
сохраните текст ошибки.

## Сборка из исходников

Нужны JDK 17–21, Maven 3.9+ и EDT 2026.1.2, указанная в
[`releng/edt-2026-1.target`](releng/edt-2026-1.target). Локальная ЕДТ нужна
только для компиляции и не упаковывается в архив.

```bash
mvn verify
```

После успешной сборки ZIP-репозиторий обновления находится в
`dev.edt.gitflow.repository/target/`. Этот архив можно выбрать в мастере
установки EDT. Для запуска второго экземпляра EDT с плагином из исходников
используйте конфигурацию PDE с продуктом
`com._1c.g5.v8.dt.product.application.rcp`.

Исходные требования и технические решения описаны в [`SPEC.md`](SPEC.md),
текущее состояние разработки — в [`HANDOFF.md`](HANDOFF.md), ближайшие задачи —
в [`PLAN.md`](PLAN.md).
