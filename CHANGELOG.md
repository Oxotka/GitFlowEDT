# Изменения Git Flow

## 0.10.11 — 6 октября 2026

- Длинные метки веток в графе сокращаются многоточием и не перекрывают граф и автора.

## 0.10.10 — 5 октября 2026

- Название текущей ветки обновляется сразу при смене HEAD.
- В тёмной теме поле сообщения коммита имеет чёрный фон.
- Исправлено освобождение подписки на сообщение при закрытии панели.
- Изменение раскладки перспективы ограничено текущим окном EDT.
- Убраны повторные запросы Git-ссылок при обновлении графа.

- В графе показаны метки остальных локальных и удалённых веток и тегов,
  указывающих на коммиты текущей истории.

- В стандартной перспективе Git слева расположены вкладки «Git» и
  «Репозитории Git», в таком порядке. После создания и сброса перспективы
  вкладка «Git» становится активной.
- Кнопка создания коммита без отправки называется «Коммит».

- Исправлено отображение имён и иконок объектов в конфигурациях, расположенных
  во вложенных каталогах репозитория: каталог `src` определяется на любой глубине.

## 0.10.0 — 5 октября 2026

Изменения относительно 0.9.4:

- Сообщение коммита синхронизируется между Git Flow и штатным «Индексированием
  Git», когда выбран один репозиторий. Правки видны в обоих полях; после создания
  коммита из Git Flow сообщение очищается в обеих панелях. Служебный текст
  слияния также можно редактировать в любом из полей.
- В контекстном меню текущего коммита (HEAD) добавлена «Слить…». Она вызывает
  штатную команду «Групповая разработка → Слить (merge)…» с контекстом проекта.
- Файлы в репозитории вне проектов EDT можно открывать в редакторе, сравнивать
  с индексом или HEAD и открывать в штатном редакторе разрешения конфликтов.
- Исправлена ошибка открытия Git-панели.

### Установка и обновление

Выберите `GitFlow-0.10.0.zip` через «Справка → Установить новое ПО… → Добавить… →
Архив…», установите Git Flow и перезапустите EDT. Архив распаковывать не нужно.
Подробная инструкция и сведения о совместимости — в [README.md](README.md).
