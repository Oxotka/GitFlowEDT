Установка

  1. В EDT откройте Справка → Установить новое ПО…
  2. Нажмите Добавить…, укажите имя Git Flow и вставьте ссылку в поле адреса
  3. Выберите Git Flow, завершите установку и перезапустите EDT
  4. Откройте перспективу Git или панель через Окно → Показать представление → Другие… → Git Flow → Git

Обновить плагин

Откройте Справка → Проверить обновления. EDT проверит добавленный сайт и предложит новую версию Git Flow

Уже установили из ZIP? Добавьте эту ссылку в доступные сайты ПО в настройках EDT, затем проверьте обновления

Установить из архива

Скачайте ZIP из последнего релиза. В окне установки выберите Добавить… → Архив… и укажите файл
