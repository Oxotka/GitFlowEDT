# Дальнейшие работы — Git Flow Ops

Текущая точка — preview **0.8.8**. Главный критерий — удобство разработчика в
EDT на Windows и безопасная работа с Git. Core-сценарии проверены автоматически;
до публичного релиза приоритет — целевая ручная проверка и установка/обновление.

## 1. Проверка на Windows EDT 2025.2.6

- [ ] Установить `dist/gitflow-ops-0.8.8-preview.zip` через **Справка → Установить
  новое ПО**, проверить обновление поверх предыдущей версии и перезапуск EDT.
- [ ] Проверить открытие панели, автовыбор репозитория, переключение репозитория
  и ветки, список избранного, папки и удалённые ветки.
- [ ] Проверить изменения в стандартном Git Staging и нашей панели: создание,
  сохранение, подготовка/возврат одного и многих файлов, отмена изменений,
  новый неотслеживаемый файл, контекстные меню, stash/pop.
- [ ] Проверить Commit, Commit + Push и Sync Changes; авторизацию, новую ветку без
  upstream, Fetch без обновления файлов и Push без лишнего обновления workspace.
- [ ] Проверить Smart Push при расхождении веток: безопасный rebase, совпавший
  изменённый файл, открытие штатного merge EDT, разрешение конфликта, merge-коммит
  и отсутствие автоматического push после merge.
- [ ] Проверить основную кнопку штатного EGit Staging: отсутствие мелькания rebase,
  повторное обновление счётчиков и сохранение штатного поведения при несовместимости.
- [ ] Проверить команды истории: выбор только текущей ветки, ветка/upstream подписи,
  переключение ветки, detached HEAD, длинный текст/автор, ширина и высота панели,
  «Показать ещё», создание ветки/метки, Compare, cherry-pick и Reset с подтверждением.
- [ ] Проверить ветвление и слияние через стандартные окна EDT: мастер создания ветки,
  локальные/удалённые ветки, теги, штатные параметры Merge и разрешение конфликта.
- [ ] Проверить работу с большим репозиторием и сетевыми ошибками; убедиться, что
  сборка workspace не вызывает долгую задержку Git-панели.

- [ ] Проверить иконки метаданных, доступность с клавиатуры, масштабирование и

## Завершённые основные этапы

- [x] Core-команды stash/pop, безопасные checkout, commit, pull/push/fetch, работа
  с ветками, перенос коммитов, ссылки на Git-хостинги.
- [x] Панель в стиле повседневного Git-интерфейса EDT: одно дерево изменений,
  адаптивный commit/sync, массовые команды, контекстные меню и история операций.
- [x] Группировка веток по папкам, избранное, быстрый поиск и сохранение избранной
  удалённой папки сверху.
- [x] Передача конфликтного слияния штатному механизму EDT без автоматической
  отправки результирующих коммитов.
- [x] Компактная история текущей ветки с графом, ограниченными метками текущей
  ветки/upstream, постраничной загрузкой и полезными командами в контекстном меню.
- [x] p2-архив preview и headless-проверка core (`mvn verify`, 41 тест).

После каждого изменения: повысить preview-версию, выполнить `mvn verify` и
`git diff --check`, проверить состав ZIP. Архивы сборок остаются локальными;
коммитить код и документацию, пушить только по отдельному поручению.
