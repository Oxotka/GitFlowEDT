# HANDOFF — Git Flow Ops

Состояние на 2026-10-03. Рабочая версия — **0.8.8 preview**. Пользователь работает
в Windows с EDT 2025.2.6; разработка и сборка выполняются на Mac с EDT 2026.1.1.
Основные документы: `README.md` — установка и работа, `SPEC.md` — исходные
требования, `PLAN.md` — ближайшие шаги.

## Что реализовано

- Устанавливаемый p2-архив для **Справка → Установить новое ПО**. Текущий локальный
  файл: `dist/gitflow-ops-0.8.8-preview.zip`. Архивы версий не коммитить.
- Отдельная Git-панель: автоматический выбор единственного/первого репозитория,
  переключение между несколькими репозиториями, текущая ветка в заголовке.
- Одно дерево с группами «Изменения» и «Подготовлено». Индексация через +/−,
  массовая подготовка/возврат, отмена правок отслеживаемых файлов с подтверждением,
  удаление новых файлов при отмене всех изменений. Операции сверяются с реальным
  состоянием Git; обновления индекса EGit используются для быстрой синхронизации.
- Контекстные меню для файлов и групп: открыть diff/файл/историю, подготовить,
  вернуть в изменения, отменить изменения, спрятать изменения. Контекстные команды
  ограничены основными сценариями. Быстрые stash/pop доступны из панели.
- Многострочное сообщение коммита, получение merge-сообщения EDT и адаптивная
  основная кнопка Commit / Commit + Push / Sync Changes. Отправка после коммита
  включена по умолчанию и настраивается рядом с кнопкой. Ctrl+Enter запускает коммит.
- Smart Pull/Push и Fetch: предварительная проверка удалённого состояния,
  безопасное обновление, отсутствие force push. Конфликт одинакового файла останавливает
  автоматический rebase и передаёт разрешение штатному механизму EDT. EDT завершает
  merge и создаёт merge-коммит; автоматической отправки после этого нет.
- Основная кнопка штатного Git Staging EGit использует Smart Push. Во время операции
  панель скрывает промежуточные действия rebase и затем обновляет состояние.
- Переключение веток через выбор с поиском, папками, избранным и удалёнными ветками;
  избранное всегда сверху, удалённую папку можно закрепить. В штатном окне Merge
  заменяется только список веток, параметры слияния остаются EDT/EGit. Создание
  ветки открывает мастер EDT.
- Компактная история **текущей выбранной ветки**, граф, автор, дата/хеш/полное сообщение
  в подсказке, постраничная загрузка. Подписи ограничены текущей локальной веткой и
  её настроенной удалённой веткой; при detached HEAD отображается HEAD. Связь веток
  показана рамкой справа в строке автора. История контекстного меню включает открытие
  коммита и удалённой ссылки, создание ветки/метки штатными мастерами, cherry-pick,
  сравнение с веткой/точкой слияния/выбранной ссылкой, штатный Reset Soft/Mixed/Hard
  и копирование хеша/сообщения.
- Ссылки на GitHub/GitLab/Bitbucket и универсальная ссылка для иных серверов.
- Плагин не блокирует обычную сборку workspace из-за фонового обновления Git;
  операции, способные менять файлы, отделены от Fetch/Push.

## Проверено

- Mac: `.tools/bin/mvn -q -o -Dmaven.repo.local=/private/tmp/gitflow-m2-review verify`
  успешно; **41 core-тест**, включая историю только выбранной ветки и фильтрацию
  посторонних меток.
- `git diff --check` чистый. ZIP 0.8.8 проверен `unzip -t`.
- Ручная проверка в Windows EDT 2025.2.6 обязательна: большая часть UI и интеграции
  EGit использует внутренние API и пока проверялась на dev-среде Mac/EDT 2026.1.1.

## Ключевые ограничения

- Рабочая target-платформа сборки привязана к локальному p2-пулу EDT 2026.1.1 на Mac
  (x86_64 под Rosetta); переносимый публичный build target ещё не подготовлен.
- Интеграция со штатными EGit Staging, Merge и Reset опирается на API, которое может
  отличаться между версиями EDT. При несовместимости часть адаптеров сохраняет штатное
  действие, но это нужно проверить на целевой версии.
- Автотесты покрывают core на временных Git-репозиториях, но не тестируют SWT/EDT UI.
- Не проверены в целевой Windows-среде авторизация к серверам, обновление уже
  установленного плагина, конфликтный merge, создание копии базы мастером EDT,
  поведение на больших репозиториях и узком окне панели.

## Как собрать

```bash
./.tools/bin/mvn -q -o -Dmaven.repo.local=/private/tmp/gitflow-m2-review verify
cp dev.edt.gitflow.repository/target/dev.edt.gitflow.repository-0.8.8-SNAPSHOT.zip \
  dist/gitflow-ops-0.8.8-preview.zip
unzip -t dist/gitflow-ops-0.8.8-preview.zip
```

Локальный Maven — 3.9.9, JDK — 21, код рассчитан на Java 17. Если временный офлайн
кеш `/private/tmp/gitflow-m2-review` отсутствует, собирать без `-o` или восстановить
кеш. Target-файл: `releng/edt-2026-1.target`. При изменении кода повышать версию
preview; не включать ZIP с историческими версиями в git. Коммиты — на русском,
без `Co-Authored-By`. Не пушить без отдельной просьбы.
