# Инструкции для работы с репозиторием

## Проект

Git Flow — плагин для 1C:EDT. Исходники на Java 17, сборка Eclipse/PDE-плагина
выполняется Maven и Tycho.

Перед изменениями смотри документы по назначению:

- `README.md` — возможности, установка и сборка;
- `SPEC.md` — архитектура и принятые технические решения;
- `PLAN.md` — незакрытые проверки и дальнейшие задачи;
- `HANDOFF.md` — актуальное состояние и ближайшее продолжение.

## Проверка и сборка

- Полная проверка: `mvn verify` (нужны JDK 17–21, Maven 3.9+ и EDT для target-платформы).
- Проверяй итоговый установочный архив: `unzip -t <путь-к-архиву>`.
- Для изменений плагина запускай все 41 core-тесты вместе с полной сборкой.
- Не считай совместимость с версией EDT подтверждённой только потому, что сборка
  или установка прошла на другой версии.

## Сборка и релиз

- `releng/edt-2026-1.target` сейчас содержит локальный путь к EDT на macOS.
  На другой машине его нужно заменить на каталог `plugins` установленной EDT,
  прежде чем собирать исходники. Это не влияет на установку готового p2 ZIP.
- Один p2 ZIP содержит плагины Git Flow и метаданные установки; не вкладывай в
  него саму EDT или системные библиотеки.
- Текущая версия — 0.8.8. При новом релизе синхронно обновляй версии в Maven
  POM-файлах, OSGi-манифестах и `dev.edt.gitflow.feature/feature.xml`.
- Не коммить собранные ZIP-архивы. Публикуй их как assets GitHub Release только
  по прямой просьбе пользователя.
- Не коммить и не пушь без прямой просьбы. Не добавляй локальные скриншоты,
  кеши, секреты и настройки машины без проверки и согласования.
- Коммиты пиши по-русски, без `Co-Authored-By`.

## Что считать подтверждённым

Актуальная ручная проверка и известные ограничения записаны в `HANDOFF.md`.
Если тесты или версия EDT не проверены, так и указывай — не выдавай заявленную
совместимость за фактически проверенную.
